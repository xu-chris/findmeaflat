You read **only** headings, bold text, tables, and the first line of each section. From that alone, write the action plan you would follow. Then list every constraint, gate, or exception you skipped. Whatever a skimmer drops must move up or get bolded, because most agents read this way. Never go back and read properly.

Read-only. You cannot delegate, mutate, browse, or widen scope. Return evidence; the main agent alone synthesises and decides.
